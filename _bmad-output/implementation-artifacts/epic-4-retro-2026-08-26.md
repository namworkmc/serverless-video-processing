### Diff-scope review lenses (consolidated)

**F1 — FR-19's automated structural proof has an underscore-shaped hole** [adversarial + verification-gap convergence; verified]. `test_no_other_tf_file_references_the_function` (`lambdas/search_rebuild/tests/test_terraform_admin_only.py:93-104`) asserts only the hyphenated literal `"search-rebuild"` absent from other `.tf` files — but cross-file Terraform references use the resource ADDRESS (`aws_lambda_function.search_rebuild.arn`, underscores), the exact idiom every ESM/route in this repo uses (`terraform/search.tf:204-211`). An EventBridge target, route, or ESM wired in any other file referencing the function by address passes check (a) (which scans only `search-rebuild.tf` itself), check (b) (hyphen-only grep), AND the integration stage (the handler ignores its invocation payload by contract) — CI green while FR-19 is violated. The constraint HOLDS as-built today (verified: only `search-rebuild.tf` mentions the function); the gap is in the guard. Disposition: **fix now** (action item AI-15).

**F2 — Read-lambda Scan truncation is silent while the rebuild warns loudly** [verification-gap + adversarial convergence; verified site]. `search_query/handler.py:71-74` ignores `LastEvaluatedKey` with no warning and no test seeding truncation; the sibling rebuild handler pins the opposite rule (`search_rebuild/handler.py:87-91` warns loudly, `test_search_rebuild.py:288-306`). Single-scan itself is spec-sanctioned (NFR-7), and the shape is inherited from `history_query` — but once the index exceeds one Scan page (~1 MB), search silently returns partial 200s while the project's own newer convention says that condition must be observable. Disposition: **fix now (small)** — one warning line + parity unit pin on both read lambdas (action item AI-17); the single-scan scope itself stays.

**F3 — One malformed index row 500s every search** [adversarial + edge-case convergence]. Projection indexes all four fields directly inside `sorted()` (`search_query/handler.py:75-83`); a partial/foreign row (realistic vector: hand-seeded manual testing) raises KeyError → mapped 500 for ALL queries until the row is manually deleted. Both real writers validate fields before writing, so this requires operator action to trigger. Disposition: **defer** (lab posture; guard snippet recorded).

**F4 — No DLQ/redrive: deterministic failures would retry forever** [adversarial + edge-case convergence]. Queue has no redrive policy and the ESM no retry ceiling (`terraform/search.tf:37-43,204-212`); a non-throttle ClientError (e.g. ValidationException on an oversize title) raises like a transient error. Spec-sanctioned v1 philosophy ("no DLQ" is in spec-4-1's Never list; poison classes handled deterministically in-handler; parity with the history leg). Disposition: **accept** (documented lab limitation; stop re-flagging).

**F5 — Rule pattern pins `detail-type` but not `source`** [adversarial; verified]. Both processed-rules match any publisher carrying `video.processed` on the bus (`terraform/search.tf:74-76`, inherited from `history.tf:74-76`). The closed-publisher allow-list is convention (AD-6), so anything that can `put_events` can forge index content (last-writer-wins PutItem). Same trust-posture class as the tracked eventId-cross-check deferral. Disposition: **defer** — extend the existing deferred-work entry to name BOTH legs' rules.

**F6 — eventId validated but unused** [adversarial]. `search_consumer/handler.py:112-122` requires a non-empty eventId then uses it only for logging — same "validation theater" posture already tracked for the history consumer (deferred-work.md Story 3.1 entry). Disposition: **defer** (extend existing entry; spec-level decision).

**F7 — Orphan index entries have no cleanup path** [adversarial]. TOCTOU between metadata validation and index write, plus rebuild structurally never deletes: delete a video after indexing and the entry outlives its source forever, and rebuild canonizes it. Spec explicitly scoped stale-entry sweeping out (Ask First, spec-4-3). Consequence bounded by AD-3 (derived, disposable). Disposition: **accept** (scope decision recorded).

**F8 — Rebuild truncation is log-only, not machine-readable** [adversarial]. The summary `{scanned, indexed, skipped}` carries no `truncated` flag (`search_rebuild/handler.py:82-92,135`), so a direct-invoke caller cannot programmatically detect a partial rebuild. Small hardening. Disposition: **defer**.

**F9 — Integration suite couples on serial execution** [adversarial]. `clear_search_index()` wipes the shared table mid-suite (`tests/integration/conftest.py:368-383`); correct only under serial order — a latent flake source if pytest-xdist ever arrives. Disposition: **accept** (recorded; revisit only if parallelization happens).

**F11 — Minor robustness notes** [adversarial/edge-case]: duplicate title literal in `bruno/upload-video.bru:15,28` (edit one, poll the wrong needle for 120 s); private `status._now_iso()` used cross-module by both new handlers (rename would break zips simultaneously); Unicode-normalization mismatch between stored titles and needles (silent false-negative on accented titles). Disposition: **defer** (cosmetic/lab-scale).
